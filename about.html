What it is

A complete intelligence profile of your digital environment

IntelReap is a Network and Device Intelligence Center — a single tool that builds a complete intelligence profile of your connection, device, browser, and security posture in real time.

Unlike traditional network scanners that require software installation, server-side processing, or account registration, IntelReap is a static web application. Open it in any browser and your scan begins immediately.

The intelligence data it produces is identical to what every server and website you connect to can already observe about your device. IntelReap makes that data visible to you.

How it works

Browser APIs. Local processing. Nothing leaves your device.

IntelReap uses standard web browser APIs to collect intelligence data directly within your browser. No plugins, no downloads, and no backend processing of your scan data is required.

  • Network data is collected using the Browser Network Information API and WebRTC APIs
  • Device data is gathered from navigator, screen, and hardware concurrency APIs
  • Security posture is assessed using permission queries and connection inspection
  • Performance is measured using the Performance Observer and Web Vitals APIs
  • Graphics capability is detected using WebGL context queries
  • Browser capabilities are tested live — 56 features probed in real time

IP geolocation enrichment requires a single outbound query to look up your public IP address. This is the only data that leaves your browser during a scan — and it is the same information already visible to every server you connect to on the internet.

Privacy architecture

Designed from the ground up to collect nothing

IntelReap's privacy-first architecture is not a policy decision — it is a technical constraint built into how the tool is constructed.

01 No database. IntelReap has no user database, no scan history database, and no analytics database. There is no infrastructure capable of storing your intelligence data.
02 No account system. No registration means no email address, no password, and no identity to link scan results to. Every scan is anonymous by construction.
03 Static deployment. IntelReap is a static web application served from a CDN. The delivery server has no ability to receive or process your scan data.
04 No analytics scripts. IntelReap loads no third-party analytics. There are no page view trackers, no session recorders, and no behavioural analytics of any kind.
05 Minimal local storage. The only data stored on your device is your language preference and cookie notice response — both in browser localStorage, both clearable at any time.
