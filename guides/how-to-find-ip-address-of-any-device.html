Quick Answer

Which IP address do you need?

To find your public IP address, use the live check on this page. To find your device's own address, run ipconfig on Windows or open the Wi-Fi details on Mac, Linux, iPhone and Android. For another device, read your router's device list. For a website, run nslookup or dig. The right method depends on which address you mean.

The address websites see is your public IP address. The live check above shows it, with your ISP and an approximate location. Other ways to see it: search for "what is my IP" on Google, which shows it at the top of the results; run curl ifconfig.me in a terminal, which prints it on one line; or on Windows run nslookup myip.opendns.com resolver1.opendns.com. The last two ask an outside service, so they need a connection.

If you need a different address, start from the case below.

Your home has one public address shared by every device, and each device has its own local address. What Is an IP Address? explains the difference in full.

02 Find Your Device's Own IP Address

Your device's own address is a local address, the one your router gave it, usually starting 192.168 or 10. It is different from the public address above, which belongs to the whole home network.

03 Find Your Router's IP Address

Your router's local address is the default gateway that your devices send traffic to. On Windows, run ipconfig and read the Default Gateway line. On a Mac, open Network Details and read Router. On an iPhone, open the info icon next to your Wi-Fi network and read Router. On Android, tap your network and look for Gateway, sometimes under Advanced. Type it into a browser's address bar to open the router's settings page.

Our guide to finding your router's IP address shows which ipconfig lines to read and what to do when the page will not open.

04 Find the IP Address of Another Device on Your Network

The router handed every device its address, so the router's device list is the most complete place to look. Open your router's page, find Connected devices, DHCP clients or Device list, and match the device by name or manufacturer. The address is on the same row.

Three ways to list devices
MethodWhat it showsLimit
Router device listEvery device the router gave an address toNeeds the router login
arp -a on WindowsDevices this computer has recently talked to (its ARP cache)A device it has not contacted will not appear; ping it first
Scanner app, such as Fing or Advanced IP ScannerDevices that answer a scan of the network rangeNeeds an install; a device that ignores the scan will not appear

Printers. A printer shows its address on its own screen or on a printed network page, and Windows keeps it in the printer's port. Our printer IP guide covers Brother, HP, Epson and Canon.

Roku. With a remote, open Settings, then Network, then About. Without one, the Roku mobile app on the same Wi-Fi shows the same details under Devices, or you can read the Roku's row in the router's device list.

05 Find the IP Address of a Website or Game Server

A site name is turned into an address by DNS, and you can ask for the answer directly. On Windows, run nslookup example.com and read the Address lines under the answer. On a Mac or Linux, run dig +short example.com. ping example.com also prints the address (ping -n 1 on Windows, ping -c 1 on Mac and Linux).

For a game server shown as play.example.com:25565, use only the name before the colon, because the number after it is the port, not part of the address. Large sites can return several addresses, and the one you get can depend on where you ask from, so the result is an address you were given, not the only one.

06 Find Someone Else's IP Address

You cannot look up a stranger's address from outside. You can only see an address that contacted you: your own web server's logs show the addresses of visitors, and the full headers of an email show the servers that handled it. Either one points to an ISP or a mail server and an approximate region, not to a person or a street address, as what an IP address reveals explains.

Do not try to track individuals from an address. For harassment or threats, report them to the platform or the police, who can ask the ISP for the account details.

07 Why the Address You Find May Not Be the One You Expect

Two tools can report different public addresses for the same home, and neither need be wrong. A VPN changes the address websites see: with it on, the live check shows the VPN server's address, not your ISP's. The VPN and Proxy panel flags this.

A VPN can still leak your real address through WebRTC. The WebRTC leak test checks for it.

Logic

Start from which address the reader needs, because the same question has different answers: the address websites see, the address of this device, the router, another device or a website. Each section answers one case and links to the guide that goes deeper.

Methodology

Commands and menu paths follow Microsoft documentation for ipconfig and arp, the macOS dig manual, and TP-Link support pages for Windows, Mac, Chromebook and phones. The terminal methods for your public address come from independent guides (DigiCert, Avast, GeeksforGeeks) and depend on outside services. The Roku route is confirmed by several independent guides, not by Roku's own page. The Microsoft nslookup page was carried over from the previous version and not reopened. That large sites can return several addresses depending on where you ask is general DNS behaviour, not tied to a cited page. Menu names vary by version and maker, and steps were not run on every device.
