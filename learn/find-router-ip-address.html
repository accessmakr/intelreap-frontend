Quick Answer

Your router's IP address is your default gateway

Your router's IP address is the default gateway your device already uses. On Windows run ipconfig and read Default Gateway. On Mac use route -n get default, on Linux ip route, and on iPhone open Wi-Fi, tap the network's info icon and read Router. Common values are 192.168.0.1, 192.168.1.1 and 10.0.0.1.

    02 What the Router Address Really Is

    When your device wants to reach anything outside your own network, it hands the traffic to one address: the default gateway. On a home network that is your router, so the router address and the default gateway are the same thing. Sending off-network traffic to a default gateway is standard host behaviour (RFC 1122). The router has a private address facing your devices and a public one facing the internet. The difference between them is covered in What Is an IP Address?

    03 Reading ipconfig Without Getting Lost

    On Windows, ipconfig prints every adapter, including ones that are not connected. Find the adapter that has an IPv4 address and a Default Gateway. When IPv6 is on, the gateway appears twice: an address beginning fe80:: (an IPv6 link-local address, defined in RFC 4291) and the IPv4 address on the next line. The IPv4 line is the one you type into a browser.

    04 If You Cannot Check a Device

    The router label is the most reliable source. If you cannot read it, the addresses routers most often use are 192.168.0.1, 192.168.1.1, 10.0.0.1 and 192.168.1.254. These are conventions, not rules, and an ISP box may use something else. Typing a wrong private address into a browser is harmless: it simply fails to load.

    06 Login Details and Resetting a Router

    Many routers print the admin name and password on a label. Some units print a unique password and others use a shared default, which is unsafe, so change it after you sign in. If you changed it and lost it, the reset button returns the router to factory settings.

    Before you reset: a reset erases your Wi-Fi name and password and any ISP login details. Have your ISP account details ready, and expect to set the router up again from scratch.

    Once you are signed in, the router is also where you change DNS for every device on the network: see how to fix slow DNS lookup.

    07 Double NAT and Carrier-Grade NAT

    If two routers each translate addresses, you have double NAT. It usually breaks port forwarding and can make online games report a strict connection. To check, sign in to your router and read the address on its Internet or WAN page. A private address there (192.168.x.x, 10.x.x.x or 172.16.x.x to 172.31.x.x, the ranges in RFC 1918) usually means another device is translating in front of yours. An address from 100.64.0.0 to 100.127.255.255 means your ISP uses carrier-grade NAT (RFC 6598), and only the ISP can change that.

    The usual fix is to put the ISP box in bridge mode, or to set your second router to access-point mode.

    08 The Router Address Is Not the Address Websites See

    The router address you found here is the private side. The address websites see is your public address, shown in the Network Identity panel.

    Many ISP boxes combine the modem and the router in one device, and the gateway for your devices is the router part. If you are looking for a printer rather than the router, use the printer IP guide.

    09 IPv6 Gateways Look Different

    On IPv6 the default gateway is often a link-local address beginning fe80::. It works, but it is not what you type into a browser. Use the IPv4 gateway shown in the same output to open the router page.
