Quick Answer

Your router's IP address is your default gateway

Your router's IP address is the default gateway your device already uses. On Windows run ipconfig and read Default Gateway. On Mac use route -n get default, on Linux ip route, and on iPhone open Wi-Fi, tap the network's info icon and read Router. Common values are 192.168.0.1, 192.168.1.1 and 10.0.0.1.

01 What the Router Address Really Is

Step picker

    Android menus differ by phone maker. If you do not see Gateway, open the network details and choose Advanced or View more.

    Network Route panel

    Who owns your network?

    A router has two addresses: a private one inside and a public one outside. The Network Route panel shows the owner of your public address. The difference is explained in What Is an IP Address?.

    Open Network Route

    When your device wants to reach anything outside your own network, it hands the traffic to one address: the default gateway. On a home network that is your router, so the router address and the default gateway are the same thing.

    Router address, gateway and public address
    TermWhat it isExample
    Router (LAN) addressAddress of the router inside your network192.168.1.1
    Default gatewayThe address your device sends outside traffic to. Same as the router LAN address192.168.1.1
    Public (WAN) addressAddress the internet sees, from your ISP203.0.113.7

    02 Where Each Device Shows It

    You do not need to guess. Each system stores the gateway and will show it with one command or one menu.

    03 Windows: ipconfig

    The ipconfig command prints every adapter. Use the one that is connected, normally Wi-Fi or Ethernet, and read its Default Gateway line.

    04 Mac and Linux

    On a Mac, route -n get default prints the gateway, and System Settings shows it under the network details. On Linux, ip route lists the default route with its next hop address.

    05 iPhone and Android

    Phones show the gateway in the Wi-Fi details for the network you are on. On iPhone it is called Router. On Android the label is Gateway or Router, sometimes behind an Advanced section.

    06 Common Default Addresses

    If you cannot check a device, these are the addresses routers most often use. They are conventions and your router may differ, especially an ISP box. Once you have the address, open it in a browser and sign in with the admin details on the router label.

    07 Modem, Router and the Public Address

    The router address you find here is the private side. The address websites see is your public address, shown in the Network Identity panel. If a device lists a modem and a router separately, the gateway for your devices is the router. To find other devices, try our guide to finding the IP address of any device or the printer IP guide.

    08 Can't Open the Router Page

    If the address does not load, the cause is usually your connection, not the router. Check these in order.

    Router page will not open
    SymptomLikely causeFix
    Page times outPhone is on mobile data or a VPNTurn off mobile data and any VPN, and join the router's Wi-Fi
    Page does not loadTyped the wrong addressUse the Default Gateway from the steps above, not a guess
    Certificate or security warningRouter uses https with its own certificateTry http:// first, or continue past the warning on your own router only
    Works on one browser onlyCache or an extension is interferingUse a private window or another browser
    Nothing respondsRouter needs a restartPower it off for 30 seconds and try again, ideally over a cable

    09 Login Details and Resetting a Router

    Many routers print the admin name and password on a label. Some units print a unique password and others use a shared default, which is unsafe, so change it after you sign in. If you changed it and lost it, the reset button returns the router to factory settings.

    Before you reset: a reset erases your Wi-Fi name and password and any ISP login details. Have your ISP account details ready, and expect to set the router up again from scratch.

    10 Double NAT and Carrier-Grade NAT

    If two routers each translate addresses, you have double NAT. It breaks port forwarding and can make online games report a strict connection. A sign is that your router's WAN address is private, such as 192.168.x.x or 10.x.x.x, instead of public. A WAN address in 100.64.0.0/10 means your ISP uses carrier-grade NAT, and only the ISP can change that.

    The usual fix is to put the ISP box in bridge mode, or to set your second router to access-point mode.

    11 IPv6 Gateways Look Different

    On IPv6 the default gateway is often a link-local address beginning fe80::. It works, but it is not what you type into a browser. Use the IPv4 gateway shown in the same output to open the router page.

    Logic

    Define the term first (router address equals default gateway), then show where each device reveals it, then give the fallback list and the difference between private and public addresses to prevent the most common mix-up.

    Methodology

    Commands and menu names follow the default behaviour of current Windows, macOS, Linux, iOS and Android. Phone menus vary by maker and version, so the page names the label to look for. Default addresses are listed as conventions only and were not tied to specific brands.
