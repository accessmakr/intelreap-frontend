Quick Answer

An IP address is a device's network address

An IP address (Internet Protocol address) is a number that identifies a device on a network and tells other devices where to send data. IPv4 addresses look like 192.168.1.42 and IPv6 addresses look like 2001:db8::1. Your home has one public address and each device has a private one.

02 What an IP Address Is

An IP address (Internet Protocol address) is a number assigned to a device on a network so that data can be sent to it and answered. It does two jobs at once: it identifies the device and it says where in the network the device sits. The format is defined in RFC 791.

The split between network and host is set by a subnet mask. That is why two devices on the same home network share their first numbers and differ only at the end.

03 Public vs Private IP Addresses

Your home has one public address from your ISP, but every phone, laptop and printer inside has a private one. A router running NAT (network address translation) rewrites private addresses to the public one on the way out. If you want to find a device inside your network, start with the guide to finding the IP address of any device.

Rule of thumb: an address starting 192.168, 10 or 172.16 to 172.31 is private. If a website shows you a different address, that one is your public IP.

04 How Data Finds You

When you open a website, your device sends a packet addressed to the site's IP address. Each router on the way reads only the destination, picks the next hop and forwards it. The reply comes back to the source address, which is how the web works without any central map. The names you type are turned into these addresses by DNS.

05 IPv4 vs IPv6

IPv4 has 232 addresses, about 4.3 billion. IANA handed its last free IPv4 blocks to the regional registries in 2011, which is why NAT is so common. IPv6, specified in RFC 8200, uses 128 bits, enough that NAT is not needed for scarcity.

06 Static vs Dynamic Addresses

Most addresses are dynamic: a DHCP server lends one to your device for a limited time, defined in RFC 2131. A static address is set by hand or reserved on the router and does not change, which suits printers and servers.

07 What Your IP Address Reveals

An IP address reveals your ISP, your network type and an approximate region. It does not reveal your name, street address or the contents of what you do. Location comes from databases that estimate it, so it can point to the wrong city, especially on mobile networks and VPNs.
