How to Find a Printer's IP Address

Find out your printer's address from its own screen, your computer, a phone app or your router, with steps for Brother, HP, Epson and Canon.

Quick Answer

Four reliable ways to find a printer's IP address

The fastest way is the printer's own screen: open its Network menu or print a configuration page. On Windows, open Printer properties and read the Ports tab, or the Web Services tab for a WSD printer. On Mac or Linux, run lpstat -v. Your router's device list also shows it. A printer on USB only has no IP address.

    02 Where a Printer Gets Its Address

    A network printer gets a private address from your router, just like a laptop does, usually through DHCP, the protocol defined in RFC 2131. Because the address is private, it only works on your own network. If you are unsure what that means, read what an IP address is first.

    The router can hand the printer a different address after a restart. Any device that saved the old address then sends print jobs to an address nobody answers.

    03 Windows 10 and 11

    Windows stores the printer address in the port the printer uses, so the answer sits in the printer's properties.

    1. Open Settings, then Bluetooth & devices, then Printers & scanners, and select your printer.
    2. Choose Printer properties and open the Ports tab.
    3. Look at the checked port. If it shows an address, often written like IP_192.168.1.50, that is the printer's address.
    4. If the port name starts with WSD-, the printer uses a WSD port and the name does not hold the address. Open the Web Services tab in the same window, where the address is listed.
    5. No address on either tab? Use the printer screen method instead.

    The PowerShell commands in the picker give the same answer for a normal TCP/IP port. For a WSD port the address column can come back empty, which is why the Web Services tab matters.

    04 Mac and Linux

    Both use CUPS. The command lpstat -v shows each printer and the device it is attached to. The device URI holds the address in forms such as ipp://192.168.1.50/ipp/print, lpd://192.168.1.50/queue or socket://192.168.1.50:9100.

    If the URI holds a name such as printer.local, the printer is found by name, and pinging that name reveals the numeric address. A dnssd:// URI carries a service name instead of an address, so use the printer screen or the router list in that case.

    05 From the Printer Itself

    Nearly every network printer can print a configuration page, often called a network status sheet or LAN details page. It lists the address, subnet mask and gateway in one place, which is useful when you also need to fix a connection problem. Printers with a screen print it from the Network or Wi-Fi menu. Printers without a screen use a button, and the manual for your model names it.

    Some printers show 0.0.0.0 until they have finished getting an address. Wait a minute and print the page again.

    07 From a Phone or Tablet

    A phone does not list other devices' addresses, so use the printer maker's app. In the HP app, tap your printer, then Network Information. Other makers' apps usually show network details in the printer or settings screen. AirPrint printers often appear by name only. If the app does not show an address, use the printer screen or the router list instead.

    08 Keeping the Address From Changing

    By default the router may hand the printer a different address after a restart, which breaks printing set up by address. Two fixes exist: a DHCP reservation on the router, or a static address set on the printer. The reservation is easier to undo and keeps all settings in one place. You set it in the router's admin page, which the router IP guide shows how to open. Method details are in our guide to finding the IP address of any device.

    09 Add a Printer by IP Address

    Adding the printer by its address is the most reliable setup, because it does not depend on automatic discovery working each time.

    1. Windows: open Settings, then Bluetooth & devices, then Printers & scanners, and choose Add device. Select Add manually, then Add a printer using an IP address or hostname. Choose TCP/IP Device as the device type, type the address and finish the wizard.
    2. Mac: open System Settings, then Printers & Scanners, and choose Add Printer. Open the IP tab and type the address. Choose the protocol your printer supports: Internet Printing Protocol (IPP) for most modern printers, or Line Printer Daemon (LPD) for some older ones. Then add it.

    Use a reservation or static address first, as described above. A printer added by an address that later changes will show as offline.

    10 Test the Connection With Ping

    A ping test separates network faults from software faults. From a computer on the same network run ping 192.168.1.50 on Windows, or ping -c 4 192.168.1.50 on Mac and Linux, using your printer's address. Replies mean the printer is reachable. No reply usually means the computer cannot reach it, but some printers ignore ping, so also type the address into a web browser: most network printers answer with their own settings page.

    Logic

    Start from what you can reach, then follow the method that needs the least access. Brand menus and the phone route come next, then how to stop the address from changing so the lookup does not have to be repeated.

    Methodology

    Windows, Mac and CUPS steps follow Microsoft, Apple and CUPS documentation. Printer menu paths come from Brother, HP, Epson, Canon and Lexmark support pages and vary by model, so the page also says how to print the status sheet. WSD- port names and the Web Services tab come from Microsoft Q&A answers written by community members, not a Microsoft reference page, and the AirPrint remark comes from a vendor blog. Steps were not run on every printer model.
