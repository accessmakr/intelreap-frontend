Quick Answer

Four reliable ways to find a printer's IP address

The fastest way is the printer's own screen: print a network configuration page or open its Wi-Fi or Network menu. On Windows, open the printer's Properties and check the Ports tab. On Mac or Linux, run lpstat -v in a terminal. Your router's connected-devices list also shows it.

    02 Where a Printer Sits on Your Network

    A network printer gets a private address from your router, just like a laptop does, usually through DHCP. Because it is private, the address only works on your own network. If you are unsure what that means, read what an IP address is first.

    03 Windows 10 and 11

    Windows stores the printer address in the port the printer uses. The Ports tab is the quickest place to read it, and the PowerShell commands in the picker give the same answer in a single line each.

    04 Mac and Linux

    Both use CUPS. The command lpstat -v lists every printer with its device address. If the address is a name such as printer.local, the printer is found by name, and pinging that name reveals the numeric address.

    05 From the Printer Itself

    Nearly every network printer can print a configuration page. It lists the address, subnet mask and gateway in one place, which is useful when you also need to fix a connection problem.

    06 Keeping the Address From Changing

    By default the router may hand the printer a different address after a restart, which breaks printing set up by address. Two fixes exist: a DHCP reservation on the router, or a static address set on the printer. The reservation is easier to undo and keeps all settings in one place. Method details are in our guide to finding the IP address of any device.

    07 Add a Printer by IP Address

    Adding the printer by its address is the most reliable setup, because it does not depend on automatic discovery working each time.

    1. Windows: open Settings, then Bluetooth & devices, then Printers & scanners, and choose Add device. Select Add manually, then Add a printer using an IP address or hostname. Choose TCP/IP as the device type, type the address and finish the wizard.
    2. Mac: open System Settings, then Printers & Scanners, and choose Add Printer. Open the IP tab, type the address, keep the protocol on IPP unless the manual says otherwise, and add it.

    Use a reservation or static address first, as described above. A printer added by an address that later changes will show as offline.

    08 Test the Connection With Ping

    A ping test separates network faults from software faults. From a computer on the same network run ping 192.168.1.50 on Windows, or ping -c 4 192.168.1.50 on Mac and Linux, using your printer's address. Replies mean the printer is reachable. No reply means the computer and printer are not talking at all.

    09 Troubleshooting: Printer Offline or Not Found

    Most printer problems come from a changed address, the wrong network, or the wrong port type. Match your symptom below.

    Printer troubleshooting
    SymptomLikely causeFix
    Offline although powered onThe address changed after a restartPrint a configuration page, then update the port address (Printer properties, Ports, Configure Port) or add a reservation
    Address starts 169.254Printer got no address from the routerCheck the Wi-Fi or cable, restart the printer and router, and confirm DHCP is on
    Works for some devices onlyDifferent network, guest Wi-Fi or client isolationPut all devices on the same network and turn off AP or client isolation
    Stopped after a new routerNew router uses a different address rangeFind the new address and re-add the printer
    Found by name but not by addressDiscovery by name works but the saved address is oldAdd the printer again by its current address
    Intermittent errors on WindowsA WSD port can lose the deviceSwitch to a Standard TCP/IP port with a fixed address

    If every step fails, restart the printer, router and computer in that order, then run the ping test again before changing anything else.

    Logic

    Start with the method needing the least access, then move to ones that need a computer or the router. Finish with how to stop the address from changing so the lookup does not have to be repeated.

    Methodology

    Commands are standard operating system tools: Windows PowerShell printer cmdlets and CUPS lpstat. Printer menu names differ between makers and models, so the page describes what to look for instead of one exact path. Steps were not tested on every printer model.
